# Data Model: Room Management System

## Core Entities

### Room (Backend)
```typescript
interface Room {
  code: string;                    // 4-6 char uppercase alphanumeric
  hostId: string;                  // Participant ID of current host  
  status: "lobby" | "active";      // Current room state
  participants: Participant[];      // All players in room
  createdAt: Date;                 // Room creation timestamp
  updatedAt: Date;                 // Last modification timestamp
}
```

**Validation Rules:**
- `code`: Must match `/^[A-Z0-9]{4,6}$/`
- `hostId`: Must match existing participant ID in participants array
- `status`: Currently only "lobby" supported (game state out of scope)
- `participants`: Minimum 0, maximum undefined (reasonable limits TBD)

**State Transitions:**
- `Room created` → `status: "lobby", participants: [creator]`
- `Player joins` → `participants.push(newParticipant)`
- `Host leaves` → `hostId = nextOldestParticipant.id`
- `Last player leaves` → `Room deleted from memory`

### Participant (Backend)
```typescript
interface Participant {
  id: string;                      // Unique participant identifier (UUID)
  name: string;                    // Display name chosen by player
  joinedAt: Date;                  // Join timestamp for host succession
  lastSeenAt: Date;                // Updated on each GET poll with participantId (heartbeat)
}
```

**Validation Rules:**
- `id`: UUID v4 format, generated by backend
- `name`: Non-empty string, 1-50 characters, trimmed
- `joinedAt`: Set to current timestamp when participant joins

### RoomSnapshot (API Response)
```typescript
interface RoomSnapshot {
  code: string;                    // Room identifier
  status: "lobby" | "active";      // Current state
  hostId: string;                  // Current host participant ID
  participants: ParticipantSnapshot[]; // Participant list
  availableWords: string[];        // Game words (from existing seed)
  roles: string[];                 // Game roles (from existing seed)
}
```

### ParticipantSnapshot (API Response)
```typescript
interface ParticipantSnapshot {
  id: string;                      // Participant identifier
  name: string;                    // Display name
  isHost: boolean;                 // Derived from room.hostId comparison
  joinedAt: string;                // ISO date string for client sorting
}
```

## Data Relationships

```
RoomStore (Map<string, Room>)
    ├── key: Room.code
    └── value: Room
            └── participants: Participant[]
                    └── hostId references participants[0..n].id

Host Transfer Logic:
    hostId → participants.find(p => p.id === hostId)
    Host leaves → hostId = participants.filter(p => p.id !== leavingId)
                                     .sort(by joinedAt ASC)[0].id
```

## Storage Implementation

**Backend (In-Memory):**
```typescript
class RoomStore {
  private rooms = new Map<string, Room>();
  
  createRoom(playerName: string): { participantId: string; room: RoomSnapshot }
  joinRoom(code: string, playerName: string): { participantId: string; room: RoomSnapshot }  
  leaveRoom(code: string, participantId: string): { success: boolean }
  getRoom(code: string): Room | undefined
  toRoomSnapshot(room: Room, viewerParticipantId?: string): RoomSnapshot
}
```

**Key Operations:**
- `createRoom`: Generate unique code, create host participant, store room
- `joinRoom`: Validate code exists, prevent duplicate joins, add participant  
- `leaveRoom`: Remove participant, transfer host if needed, cleanup empty rooms
- `toRoomSnapshot`: Transform internal Room to API response with derived fields

**Frontend (Store State):**
```typescript
interface RoomStoreState {
  room: RoomSnapshot | null;       // Current room data
  participantId: string | null;    // Current user's participant ID
  error: string | null;            // Last error message
  isLoading: boolean;              // Loading state for operations
}
```

## Validation Schemas

### Room Creation Request
```typescript
const createRoomSchema = z.object({
  playerName: z.string()
    .trim()
    .max(50, "Player name too long")
    .optional() // omitted/blank → server assigns player1
});
```

### Room Join Request  
```typescript
const joinRoomSchema = z.object({
  playerName: z.string()
    .trim()
    .max(50, "Player name too long")
    .optional(), // omitted/blank → server assigns next playerN in room
  code: z.string()
    .regex(/^[A-Z0-9]{4,6}$/, "Room code must be 4-6 uppercase letters and numbers")
    .transform(s => s.toUpperCase())
});
```

### Room Leave Request
```typescript
const leaveRoomSchema = z.object({
  participantId: z.string()
    .uuid("Invalid participant ID format")
});
```

## Error Conditions

| Condition | HTTP Status | Error Message |
|-----------|-------------|---------------|
| Room not found | 404 | "Room not found" |
| Invalid room code format | 400 | "Room code must be 4-6 uppercase letters and numbers" |
| Duplicate join attempt | 400 | "You are already in this room" |
| Player name too long (>50) | 400 | "Player name is too long" |
| Code generation failure | 500 | "Failed to generate unique room code" |
| Participant not in room | 404 | "Participant not found in room" |

## Data Flow Examples

### Room Creation Flow
```
1. POST /rooms { } or { playerName: "Alice" }
2. Backend: Generate code "ABC1", create Room, add Alice (or `player1` if name omitted) as host
3. Response: { participantId: "uuid1", room: { code: "ABC1", hostId: "uuid1", ... }}
```

### Join Room Flow  
```
1. POST /rooms/ABC1/join { } or { playerName: "Bob" }
2. Backend: Validate ABC1 exists, add Bob to participants
3. Response: { participantId: "uuid2", room: { code: "ABC1", participants: [Alice, Bob] }}
```

### Host Leave Flow
```
1. POST /rooms/ABC1/leave { participantId: "uuid1" } (Alice leaves)
2. Backend: Remove Alice, set hostId = "uuid2" (Bob), update timestamps
3. Response: { success: true }
4. Next GET /rooms/ABC1: room.hostId = "uuid2" (Bob is new host)
```

### Empty Room Cleanup
```
1. POST /rooms/ABC1/leave { participantId: "uuid2" } (Bob leaves, last participant)
2. Backend: Remove Bob, room.participants = []
3. Backend: Delete room from Map (immediate cleanup)
4. Response: { success: true }
5. Next GET /rooms/ABC1: 404 Not Found
```
